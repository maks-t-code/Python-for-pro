# Снижение размерности и визуализация данных с помощью PCA (Python + Scikit-Learn)

Проект посвящен применению метода главных компонент (**PCA**) для снижения размерности многомерного датасета химических показателей вин (`Wine dataset`). В ходе работы проводится разведочный анализ данных (EDA), оценка корреляционных связей, уменьшение признакового пространства до двух компонент и визуализация результатов.

---

## 💡 Алгоритм решения задачи

1.  **Разведочный анализ данных (EDA)**:
    *   Загрузка классического датасета `wine` из репозитория UCI (через `sklearn.datasets`).
    *   Оценка структуры и объема памяти датасета (178 строк, 14 столбцов, включая целевой признак).
    *   Расчет базовых статистик для 13 химических признаков (минимум, максимум, среднее, медиана).
    *   Проверка на наличие пропущенных значений (пропуски отсутствуют).
    *   Построение тепловой карты линейной корреляции Пирсона для оценки взаимосвязей между признаками.
2.  **Снижение размерности методом PCA**:
    *   Проекция 13 исходных признаков на 2 главные компоненты.
    *   Оценка доли объясненной дисперсии (как для нестандартизированных, так и для стандартизированных данных).
3.  **Визуализация классов**:
    *   Построение диаграмм рассеяния (Scatter Plot) в пространстве первой и второй главных компонент с цветовой дифференциацией по классам вин (`Target`).

---

## 🛠 Технологический стек и требования

Проект разработан в Jupyter Notebook на языке Python 3.x с использованием следующих библиотек:
*   `pandas` — для манипуляций с датафреймами;
*   `scikit-learn` — для загрузки данных, стандартизации (`StandardScaler`) и проведения `PCA`;
*   `matplotlib` и `seaborn` — для построения тепловых карт и финальных графиков рассеяния.

Установка необходимых зависимостей:
```bash
pip install pandas scikit-learn matplotlib seaborn
```

## 📈 Результаты экспериментов и выводы

В работе было проведено два эксперимента по снижению размерности: без предварительной стандартизации данных и с ней.

### Эксперимент 1: PCA без стандартизации признаков
*   **Доля объясненной дисперсии**: Компонента 1 — **99.81%**, Компонента 2 — **0.17%** (В сумме — **1.00**).
*   **Вывод**: Из-за отсутствия масштабирования алгоритм PCA практически полностью ориентировался на один доминирующий по абсолютным величинам признак (`Proline`). Метод формально сохранил 100% информации, однако кластеры на итоговом графике получились вытянутыми и недостаточно четко разделенными.

### Эксперимент 2: PCA со стандартизацией данных (StandardScaler)
*   **Доля объясненной дисперсии**: Компонента 1 — **36.20%**, Компонента 2 — **19.21%** (В сумме — **55.41%**).
*   **Вывод**: После приведения признаков к единому масштабу общая объясненная дисперсия снизилась до 55.4%, однако итоговая визуализация показала **гораздо более четкое и качественное разделение объектов на три обособленных кластера**. Это подтверждает необходимость стандартизации данных перед применением линейных методов снижения размерности, таких как PCA.
