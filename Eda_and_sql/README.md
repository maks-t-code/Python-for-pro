# Исследовательский анализ данных и оптимизация EAV-запросов в SQL

Репозиторий содержит комплексное решение двух практических задач: проведение разведочного анализа данных (EDA) на основе мирового датасета стоимости высшего образования, а также аудит и рефакторинг высоконагруженного SQL-запроса в архитектуре базы данных EAV (Entity-Attribute-Value).

---

## 🛠 Технологический стек

* **Язык разработки:** Python 3.13
* **Библиотеки для анализа:** `pandas`, `kagglehub`
* **Библиотеки для визуализации:** `matplotlib`
* **Базы данных:** SQL / PostgreSQL

## 📋 Структура проекта

### Часть 1: Исследовательский анализ данных (EDA)

В качестве исследуемого датасета выбран массив данных **Cost of International Education**, отражающий затраты иностранных студентов на обучение и проживание в различных университетах мира.

#### Выполненные этапы:
1. **Импорт и предобработка:** Автоматизированная загрузка актуальной версии датасета напрямую через API Kaggle без необходимости локального хранения. Преобразование в объект `DataFrame`, аудит структуры и проверка на наличие пропущенных значений.
2. **Агрегация и расчет статистик:**
   * Определен топ-10 стран по концентрации представленных высших учебных заведений.
   * Рассчитана средняя ежемесячная стоимость аренды жилья в разрезе государств.
   * Проведен сравнительный анализ общих годовых затрат (обучение, аренда за 12 месяцев, медицинская страховка и визовые сборы) для топ-15 самых дорогих стран.
   * Оценена финансовая нагрузка в зависимости от академической степени (бакалавриат, магистратура, докторантура).
3. **Визуализация:** Построены детализированные столбчатые диаграммы (включая накопительные stacked-графики) для выявления скрытых бизнес-инсайтов и трендов.

#### Ключевые аналитические выводы:
* **Аренда жилья:** Наиболее доступное жилье для студентов зафиксировано в Тунисе, в то время как США лидируют с огромным отрывом по уровню цен на недвижимость.
* **Инфраструктура:** Наибольшее количество крупных университетов, ориентированных на международный рынок, находится в Великобритании.
* **Стоимость образования:** Соединенные Штаты Америки признаны самой дорогой страной для получения высшего образования.
* **Академические степени:** Анализ показал, что получение степени магистра обходится дешевле всего, в то время как бакалавриат требует наибольших суммарных инвестиций.

### Часть 2: Оптимизация производительности SQL-запросов (EAV-модель)

Проведен аудит и рефакторинг неоптимального SQL-запроса, генерируемого ORM-системой "под капотом" для фильтрации мета-данных пользователей по схеме **Entity-Attribute-Value (EAV)**.

#### Исходная проблема:
При попытке выбрать идентификаторы пользователей, у которых заполнен хотя бы один из четырех атрибутов (`birth-date`, `phone-number`, `activity-flag`, `register-date`), система генерировала тяжелый запрос с четырьмя последовательными операциями `INNER JOIN` к одной и той же таблице `users_meta`.

* **Критический недостаток:** С ростом количества проверяемых атрибутов число джойнов растет линейно. На реальных объемах данных (сотни тысяч или миллионы строк в мета-таблице) это приводит к лавинообразному падению производительности БД, избыточному потреблению RAM/CPU и дискомфорту пользователей информационной системы.

#### Решение (Рефакторинг):
Для кардинального снижения стоимости выполнения запроса (Query Cost) избыточные множественные джойны были устранены. Достаточно выполнить всего **одно** левое или внутреннее объединение с мета-таблицей и сгруппировать условия фильтрации через логический оператор `OR` внутри блока `WHERE`.

#### Оптимизированный SQL-запрос:
```sql
SELECT DISTINCT users.id
FROM users 
    INNER JOIN users_meta AS mt ON (users.ID = mt.user_id)
WHERE 1=1 
AND (
       (mt.meta = 'birth-date' AND mt.meta_value != '') 
    OR (mt.meta = 'phone-number' AND mt.meta_value != '') 
    OR (mt.meta = 'activity-flag' AND mt.meta_value != '')
    OR (mt.meta = 'register-date' AND mt.meta_value != '')
);
```
* **Результат оптимизации:** Количество чтений таблицы `users_meta` сокращено в 4 раза. Запрос стал легко масштабируемым и устойчивым к увеличению количества атрибутов.
