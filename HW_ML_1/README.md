## 🔧 Обработка пропусков

Для заполнения пропусков использованы два метода:

### 1. Заполнение средним значением (Mean Imputation)
```python
train_mean.fillna(train_mean.mean(), inplace=True)
test_mean.fillna(train_mean.mean(), inplace=True)
```

### 2. Заполнение медианой (Median Imputation)
```python
train_median.fillna(train_median.median(), inplace=True)
test_median.fillna(train_median.median(), inplace=True)
```

**Обоснование выбора:**
- Количество пропусков невелико, удаление строк могло бы уменьшить объем обучающей выборки
- Среднее значение сохраняет общую структуру данных
- Медиана устойчива к выбросам
