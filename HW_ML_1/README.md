# Шифратор и дешифратор Цезаря на Python

Реализация классического **шифра Цезаря** для строк на русском языке. Проект включает в себя инструменты для кодирования текста с заданным шагом и автоматического декодирования методом полного перебора (**brute force**).

---

## ✨ Функционал

*   **Кодирование текста**: смещение букв русского алфавита на заданное количество позиций.
*   **Дешифрование brute force**: перебор всех возможных вариантов сдвига для расшифровки строки без исходного ключа.
*   **Сохранение структуры**: пробелы и сторонние символы (знаки препинания, цифры) сохраняются в исходном виде.

---

## 🛠 Требования

*   Python 3.x

---

## 🚀 Использование

### 1. Шифрование текста
Функция `encryption` принимает исходную строку и целочисленный размер сдвига, возвращая зашифрованный текст в верхнем регистре.

```python
def encryption(message, shift_size):
    letters = ['А','Б','В','Г','Д','Е','Ж','З','И','Й',
               'К','Л','М','Н','О','П','Р','С','Т','У',
               'Ф','Х','Ц','Ч','Ш','Щ','Ъ','Ы','Ь','Э',
               'Ю', 'Я']
    result = ''
    for s in message:
        if s in letters:
            result += letters[(shift_size + letters.index(s)) % len(letters)]
        else:
            result += s
    return result

# Пример работы:
message = "ПРИВЕТ МИР"
shift = 5
print(encryption(message, shift))  # Вывод: ФХНЗКЧ СНХ
```

### 2. Взломостойкое дешифрование (Brute Force)
Функция `decryption` автоматически перебирает все 31 вариантов сдвига русского алфавита и возвращает список кортежей формата `(сдвиг, результат)`.

```python
# Возвращает список всех возможных вариантов расшифровки
variants = decryption("ФХНЗКЧ СНХ")
```
