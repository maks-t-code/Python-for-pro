# Предсказание стоимости недвижимости с помощью Линейной Регрессии (Python + Scikit-Learn)

Проект посвящен построению и оценке модели машинного обучения для предсказания целевого признака — стоимости недвижимости (`Target`). В ходе работы выполняется разведочный анализ данных (EDA), обработка пропущенных значений различными статистическими методами и обучение модели линейной регрессии.

---

## 📊 Описание признаков датасета

| Признак | Описание |
| :--- | :--- |
| **MedInc** | Средний доход домохозяйства (в десятках тысяч долларов) |
| **HouseAge** | Средний возраст домов в районе |
| **AveRooms** | Среднее количество комнат на дом |
| **AveBedrms** | Среднее количество спален на дом |
| **Population** | Население района |
| **AveOccup** | Среднее количество человек на дом |
| **Target** | Стоимость недвижимости (целевой признак для предсказания) |

---

## 💡 Алгоритм решения задачи

1.  **Разведочный анализ данных (EDA)**:
    *   Оценка объема занимаемой памяти датасета (~1.1 MB, 20640 строк, 7 столбцов).
    *   Расчет описательных статистик для непрерывных признаков: минимум, максимум, среднее арифметическое и медиана.
    *   Анализ пропущенных значений (выявлены пропуски в столбцах `MedInc`, `HouseAge`, `AveRooms`).
2.  **Разделение выборки**: Разделение датасета на обучающую (`train`) и тестовую (`test`) выборки в соотношении 80/20.
3.  **Предобработка данных (Обработка пропусков)**:
    *   *Способ 1*: Заполнение пропущенных значений средним арифметическим (`.mean()`).
    *   *Способ 2*: Заполнение пропущенных значений медианой (`.median()`).
4.  **Обучение моделей**: Обучение двух вариантов моделей класса `LinearRegression` на очищенных данных.
5.  **Оценка качества**: Расчет и сравнение метрик `MSE`, `R²` и `MAE` для каждого подхода, а также визуализация истинных значений против предсказанных на диаграмме рассеяния.

---

## 🛠 Технологический стек и требования

Проект разработан на Python 3.x с использованием следующих библиотек:
*   `pandas` — для манипуляций с данными;
*   `numpy` — для математических вычислений;
*   `scikit-learn` — для разделения выборки, построения моделей и расчета метрик;
*   `matplotlib` — для визуализации результатов.

Установка необходимых пакетов:
```bash
pip install pandas numpy scikit-learn matplotlib gdown
```

## 📈 Результаты и выводы

### Метрики качества моделей:

*   **Модель со средними значениями**:
    *   `MSE` (Mean Squared Error): **0.643**
    *   `R² Score` (Коэффициент детерминации): **0.510**

*   **Модель с медианными значениями**:
    *   `MSE` (Mean Squared Error): **0.643**
    *   `R² Score` (Коэффициент детерминации): **0.509**
    *   `MAE` (Mean Absolute Error): **0.580**

### Итоговое заключение:
Результаты метрик качества обеих моделей практически идентичны, так как количество пропущенных значений в исходном датасете было минимальным. Однако к использованию **рекомендуется модель с заполнением пропусков средним значением**, поскольку она показала незначительно более высокий коэффициент детерминации ($R^2$). На построенных графиках рассеяния заметно небольшое смещение линии регрессии, что обусловлено наличием аномалий и выбросов в исходных данных.
