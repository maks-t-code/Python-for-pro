# Домашняя работа №2: Анализ данных о вине с применением PCA

## 📋 Описание проекта

В данной домашней работе выполняется анализ набора данных о вине (Wine dataset) с использованием метода главных компонент (PCA) для уменьшения размерности данных и визуализации классов.

## 🎯 Задачи

1. Загрузить данные о вине из sklearn.datasets
2. Провести разведочный анализ данных (EDA)
3. Проверить наличие пропусков
4. Уменьшить размерность с помощью PCA до 2 компонент
5. Оценить долю сохраненной дисперсии
6. Построить scatterplot первых двух главных компонент с цветовой кодировкой по классам

## 🔧 Метод главных компонент (PCA)

### Без стандартизации данных

```python
pca = PCA(n_components=2)
data_pca = pca.fit_transform(data.data)
```

**Результаты:**
- Объясненная дисперсия компоненты 1: 99.81%
- Объясненная дисперсия компоненты 2: 0.17%
- **Общая объясненная дисперсия: 100%**

### Со стандартизацией данных

```python
scaler = StandardScaler()
wine_scaled = scaler.fit_transform(data.data)
pca = PCA(n_components=2)
data_pca = pca.fit_transform(wine_scaled)
```

**Результаты:**
- Объясненная дисперсия компоненты 1: 36.20%
- Объясненная дисперсия компоненты 2: 19.21%
- **Общая объясненная дисперсия: ~55%**

## 📊 Визуализация результатов

### PCA без стандартизации
- Классы вина разделяются, но не четко
- Первая компонента объясняет почти всю дисперсию (99.81%)
- Кластеры частично перекрываются

### PCA со стандартизацией
- Разделение кластеров стало более четким
- Классы лучше разделены в пространстве двух компонент
- Общая объясненная дисперсия снизилась до ~55%

## 💡 Выводы

### Основные наблюдения
1. **Пропуски отсутствуют** - данные чистые и готовы к анализу
2. **Высокая корреляция** - признаки Flavanoids и od280/od315_of_diluted_wines сильно коррелируют с целевой переменной
3. **Эффективность PCA** - метод главных компонент успешно уменьшил размерность с 13 до 2 признаков
4. **Важность стандартизации** - стандартизация данных улучшает разделение кластеров при визуализации

### Сравнение подходов

| Параметр | Без стандартизации | Со стандартизацией |
|----------|-------------------|-------------------|
| Объясненная дисперсия | 100% | 55% |
| Разделение кластеров | Умеренное | Хорошее |

### Рекомендации
- Для визуализации классов вина рекомендуется использовать **PCA со стандартизацией**
