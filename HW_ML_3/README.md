# 🏃 Предсказание расхода калорий с использованием дерева решений

## 📊 Обзор проекта
В данном проекте анализируется набор данных с платформы Kaggle для предсказания количества сожженных калорий во время физической активности. Мы используем модели дерева решений, сравнивая модель без ограничений с версией с подобранными гиперпараметрами для достижения оптимальной производительности.

## 🎯 Постановка задачи
Предсказать количество сожженных калорий на основе различных физических и физиологических параметров:
- Возраст
- Пол
- Рост
- Вес
- Длительность упражнения
- Частота пульса
- Температура тела

## 📁 Набор данных
- **Источник**: Kaggle Playground Series S5E5
- **Размер**: 750,000 строк, 9 столбцов
- **Целевая переменная**: Calories (калории)

### Модель 2: Дерево решений с оптимизацией гиперпараметров
```python
param_grid = {
    'max_depth': [3, 4, 5],
    'min_samples_split': [2, 5, 10],
    'min_samples_leaf': [1, 3, 5]
}

grid_search = GridSearchCV(
    DecisionTreeRegressor(random_state=42),
    param_grid,
    cv=5,
    scoring='neg_mean_absolute_error'
)
```

**Лучшие гиперпараметры**:
```python
{
    'max_depth': 5,
    'min_samples_leaf': 1,
    'min_samples_split': 2
}
```

**Метрики производительности**:
| Метрика | Обучающая выборка | Тестовая выборка |
|---------|-------------------|------------------|
| MSE | 131.472 | 133.854 |
| MAE | 8.064 | 8.123 |
| MAPE | 0.142 | 0.143 |

✅ **Улучшение**: Настроенная модель показывает сбалансированную производительность между обучающей и тестовой выборками, устраняя проблему переобучения.
