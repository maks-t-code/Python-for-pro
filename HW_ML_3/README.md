# Прогноз расхода калорий 🏃‍♂️

Этот проект посвящен решению задачи регрессии, а именно, прогнозированию количества сожженных калорий во время физической активности на основе данных о пользователях. В качестве основной модели используется алгоритм **Дерева решений**.

## 🎯 Цель проекта

Разработать и обучить модель машинного обучения, которая сможет с высокой точностью предсказывать расход калорий по таким параметрам, как пол, возраст, рост, вес, длительность тренировки, частота пульса и температура тела.

## 📊 Данные

В работе используется набор данных с соревнования [Playground Series S5E5](https://www.kaggle.com/competitions/playground-series-s5e5) на платформе Kaggle.

*   **Источник:** Kaggle Competition
*   **Объем:** ~750,000 записей
*   **Признаки:**
    *   `Sex` (категориальный)
    *   `Age`, `Height`, `Weight`, `Duration`, `Heart_Rate`, `Body_Temp` (числовые)
*   **Целевая переменная:** `Calories`

## 🛠️ Используемые технологии

*   **Python 3.11+**
*   **Pandas, NumPy** - для обработки и анализа данных.
*   **Matplotlib, Seaborn** - для визуализации.
*   **Scikit-learn** - для предобработки данных, построения и оценки модели.

## 🔍 Этапы работы

### 1. Загрузка и анализ данных (EDA)
*   Данные загружаются из облачного хранилища.
*   Произведен общий анализ структуры данных, типов признаков и проверка на пропуски.
*   Построены визуализации для изучения корреляций признаков (`Duration`, `Heart_Rate`) с целевой переменной `Calories`.

### 2. Предобработка данных
*   Удален признак `id`, как неинформативный.
*   **Категориальные признаки:** Признак `Sex` преобразован с помощью `OneHotEncoding`.
*   **Числовые признаки:** Все числовые переменные стандартизированы с помощью `StandardScaler`.
*   **Выбросы:** Анализ показал, что выбросы в данных незначительны и лежат в пределах физиологической нормы человека, поэтому они не удалялись.

### 3. Построение и обучение модели
*   Датасет был разделен на обучающую (`train`) и тестовую (`test`) выборки в соотношении 75/25.
*   **Модель 1:** Обучение "сырого" дерева решений (`DecisionTreeRegressor`) без ограничений. Модель сильно переобучилась: `MSE` на train ~ 0.035, на test ~ 27.44.
*   **Модель 2:** Поиск оптимальных гиперпараметров с помощью `GridSearchCV`.
    *   **Лучшие параметры:** `max_depth=5`, `min_samples_split=2`, `min_samples_leaf=1`.
    *   **Результаты:** Переобучение устранено. `MSE` на train ~ 131.47, на test ~ 133.85. Значения метрик MAE и MAPE близки для обеих выборок, что говорит о хорошей обобщающей способности модели.

### 4. Оценка важности признаков
Проанализирована важность признаков для лучшей модели.
*   **Duration (продолжительность тренировки)**: ~95% важности. Этот признак является доминирующим.
*   **Heart_Rate (частота пульса)**: ~3% важности.
*   **Age (возраст)**: ~1.4% важности.

Это логично, так как чем дольше и интенсивнее (выше пульс) тренировка, тем больше калорий сжигается.

## 📈 Результаты

Лучшая модель показала следующие результаты на тестовых данных:

*   **Среднеквадратичная ошибка (MSE):** 133.85
*   **Средняя абсолютная ошибка (MAE):** 8.12
*   **Средняя абсолютная процентная ошибка (MAPE):** 14.3%

Модель хорошо справляется с задачей, давая прогнозы с ошибкой в среднем ±8 калорий, что является хорошим показателем.

## 📝 Выводы

В ходе работы была решена задача регрессии для прогнозирования расхода калорий. Ключевым фактором, влияющим на предсказание, является продолжительность тренировки. Настройка гиперпараметров с помощью `GridSearchCV` позволила построить модель, которая не переобучается и хорошо обобщается на новых данных.
