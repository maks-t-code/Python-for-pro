# Предсказание расхода калорий при физических нагрузках с помощью Дерева Решений (Python)

Проект посвящен построению и оптимизации модели машинного обучения на основе алгоритма **Дерево решений (Decision Tree Regressor)** для прогнозирования количества сожженных калорий (`Calories`) во время тренировок. В качестве исходных данных используются структурированные профили физической активности пользователей.

---

## 📊 Описание признаков датасета

| Признак | Тип данных | Описание |
| :--- | :--- | :--- |
| **Sex** | Категориальный | Пол пользователя (`male` / `female`) |
| **Age** | Числовой | Возраст пользователя (в годах) |
| **Height** | Числовой | Рост пользователя (в см) |
| **Weight** | Числовой | Вес пользователя (в кг) |
| **Duration** | Числовой | Длительность физической активности (в минутах) |
| **Heart_Rate** | Числовой | Частота сердечных сокращений (пульс, уд/мин) |
| **Body_Temp** | Числовой | Температура тела во время тренировки (в °C) |
| **Calories** | Числовой | **Целевой признак**: количество сожженных калорий |

## 💡 Этапы реализации проекта

### 1. Разведочный анализ данных (EDA)
* Проведен анализ объема памяти (~84.4 MB) и размерности датасета (750 000 строк, 9 столбцов).
* Выполнена проверка на пропущенные значения (пропусков не обнаружено).
* Построена тепловая карта корреляции Пирсона. Установлено, что признак `id` не оказывает влияния на целевую переменную и был исключен из обучения. Выявлена сильная линейная зависимость между `Duration` (длительность), `Heart_Rate` (пульс), `Body_Temp` (температура) и целевым признаком `Calories`.
* Проанализированы распределения числовых признаков с помощью диаграмм размаха (Boxplot). Выбросы признаны физиологически допустимыми нормами организма во время нагрузок.

### 2. Подготовка данных к обучению
* Данные разделены на обучающую и тестовую выборки в соотношении 75/25 с применением стратификации.
* Бинарный категориальный признак `Sex` закодирован с помощью `OneHotEncoder` (параметр `drop='first'`).
* Числовые признаки стандартизированы с помощью `StandardScaler` для корректной интерпретации моделью.

### 3. Построение и оценка моделей
В рамках исследования были обучены и сопоставлены две модели:

1. **Базовая модель (Максимальное дерево)** без ограничений на гиперпараметры.
2. **Оптимальная модель** с ограничением глубины и структуры дерева, найденная с помощью кросс-валидации и поиска по сетке `GridSearchCV`.

## 📈 Результаты и метрики качества

Для оценки предсказательной способности использовались метрики: **MSE** (Mean Squared Error), **MAE** (Mean Absolute Error) и **MAPE** (Mean Absolute Percentage Error).

| Модель / Метрика | MSE (Train) | MSE (Test) | MAE (Train) | MAE (Test) | MAPE (Train) | MAPE (Test) |
| :--- | :---: | :---: | :---: | :---: | :---: | :---: |
| **Максимальное дерево** | 0.035 | 27.443 | 0.014 | 3.124 | 0.000 | 0.053 |
| **Оптимальное дерево (`GridSearchCV`)** | 131.472 | 133.854 | 8.064 | 8.123 | 0.142 | 0.143 |

### Анализ результатов:
* **Базовая модель** продемонстрировала классические признаки **переобучения** (overfitting): идеальные метрики на тренировочной выборке и резкое падение качества (ошибка `MSE` возрастает до 27.4) на тестовых данных.
* **Оптимальная модель** со следующими параметрами: `max_depth=5`, `min_samples_leaf=1`, `min_samples_split=2` показала стабильные и сбалансированные результаты как на обучающем, так и на тестовом наборе данных (`MAE` ~8.1). Данная модель является устойчивой и рекомендуется для промышленной эксплуатации.

3. **Age (Возраст):** 1.42%
