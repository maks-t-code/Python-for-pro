# Портфолио проектов: Машинное обучение и Анализ данных (Python / SQL)

Добро пожаловать в репозиторий, объединяющий практические решения комплексных задач в области **Data Science, Machine Learning, Data Analytics и СУБД**. Проекты охватывают весь цикл работы с данными: от парсинга, очистки и интеграции баз данных до построения и глубокой интерпретации моделей машинного обучения.

---

## 🛠 Основной технологический стек

* **Языки программирования:** Python (3.11 - 3.13), SQL (PostgreSQL).
* **Машинное обучение (ML):** Scikit-Learn, XGBoost, LightGBM, CatBoost, Optuna.
* **Анализ и визуализация данных:** Pandas, NumPy, Matplotlib, Seaborn, SHAP.
* **Работа с БД и текстом:** SQLAlchemy, Psycopg2, Регулярные выражения (RegEx).

---

## 📂 Структура репозитория и навигация по проектам

Ниже представлен краткий обзор каждого модуля, входящего в состав данного портфолио. Вы можете перейти в соответствующую директорию для ознакомления с исходным кодом и детальной документацией.

### 🧠 Модуль 1: Классические алгоритмы шифрования
*   **Проект 1: [Шифратор и дешифратор Цезаря](./project_01_caesar/)**
    *   *Технологии:* Python (базовые структуры данных).
    *   *Суть задачи:* Реализация алгоритма циклического смещения символов с поддержкой регистра. Написание модуля автоматического декодирования строк методом полного перебора (**Brute Force**).

### 📊 Модуль 2: Разведочный анализ данных (EDA) и Визуализация
*   **Проект 2: [Основы анализа данных и визуализации](./project_02_eda_basics/)**
    *   *Технологии:* NumPy, Pandas, Matplotlib, Seaborn.
    *   *Суть задачи:* Статистический анализ успеваемости студентов (метрики `mean`, `median`, `std`), агрегация годовой динамики продаж бизнеса и исследовательский анализ зависимостей (Scatter/Bar/Line Plots) на реальных датасетах.
*   **Проект 5: [Разбор и структурирование геоданных из сетевых логов](./project_05_regex_logs/)**
    *   *Технологии:* Python, RegEx, Pandas, OpenPyXL.
    *   *Суть задачи:* Построчный парсинг «грязных» логов сетевого балансировщика. Экстракция географических координат и текстовых адресов, глубокая очистка строк от битых кодировок и экспорт данных на разные листы многостраничных отчетов Excel.
*   **Проект 7: [Исследовательский анализ и снижение размерности признаков](./project_07_pca_wine/)**
    *   *Технологии:* Scikit-Learn (PCA, StandardScaler), Seaborn, Matplotlib.
    *   *Суть задачи:* Комплексный EDA многомерного датасета химических показателей. Применение метода главных компонент (**PCA**) для проекции признаков на 2D-пространство. Сравнительный анализ эффективности разделения классов с предварительной стандартизацией данных и без неё.

### 💾 Модуль 3: Интеграция баз данных и SQL-оптимизация
*   **Проект 3: [Автоматизация обработки медицинских анализов](./project_03_sql_medicine/)**
    *   *Технологии:* Python, PostgreSQL, Pandas, Psycopg2.
    *   *Суть задачи:* Интеграция локальных данных Excel со справочниками реляционной СУБД. Разработка скриптов для автоматического выявления критических отклонений в анализах пациентов (количественные нормы и качественные маркеры).
*   **Проект 6: [Оптимизация производительности SQL в архитектуре EAV](./project_06_sql_eav_optimization/)**
    *   *Технологии:* SQL, PostgreSQL, Kaggle API.
    *   *Суть задачи:* Проведение EDA глобального датасета стоимости высшего образования. Аудит и рефакторинг неоптимального SQL-запроса к сущностям EAV (Entity-Attribute-Value): устранение лавинообразных `INNER JOIN` операций и сокращение стоимости выполнения запроса (Query Cost) в 4 раза.

### 🤖 Модуль 4: Прогнозное моделирование и Бустинг (Регрессия)
*   **Проект 4: [Очистка текстовых данных и Линейная Регрессия](./project_04_regex_regression/)**
    *   *Технологии:* Python, SQLAlchemy, RegEx (`re`), Scikit-Learn.
    *   *Суть задачи:* Нормализация хаотичных комментариев пользователей к платежам с помощью RegEx (точность совпадения с эталоном **99.01%**). Построение модели линейной регрессии для прогнозирования стоимости недвижимости с оценкой стратегий заполнения пропусков (Mean/Median) по метрикам $R^2$, MSE, MAE.
*   **Проект 8: [Прогнозирование расхода калорий (Decision Tree)](./project_08_decision_tree/)**
    *   *Технологии:* Python 3.13, Scikit-Learn (`DecisionTreeRegressor`), GridSearchCV.
    *   *Суть задачи:* Построение модели дерева решений для предсказания энергозатрат на основе профилей активности. Борьба с переобучением базового дерева через оптимизацию гиперпараметров по сетке. Расчет важности признаков (Feature Importance).
*   **Проект 9: [Ансамблирование и Градиентный бустинг](./project_09_boosting_ensembles/)**
    *   *Технологии:* RandomForest, XGBoost, LightGBM, CatBoost.
    *   *Суть задачи:* Развертывание и сопоставление мощных ансамблевых алгоритмов. Тюнинг параметров градиентного бустинга с оценкой качества по метрикам MSE, MAE, MAPE. Финальный выбор наиболее стабильной и устойчивой модели для промышленной эксплуатации.

### 🔮 Модуль 5: Классификация, Временные ряды и Интерпретация ML
*   **Проект 10: [Прогнозирование оттока клиентов банка (Pipeline & SHAP)](./project_10_bank_churn_classification/)**
    *   *Технологии:* Scikit-Learn Пайплайны, Optuna, SHAP values, XGBoost, CatBoost.
    *   *Суть задачи:* Проектирование автоматического сквозного конвейера обработки данных (`Pipeline` + `ColumnTransformer`). Построение моделей классификации и подбор параметров через `OptunaSearchCV`. Раскрытие механизма принятия решений («черного ящика») бустинга с помощью глобальной и локальной интерпретации **SHAP**.
*   **Проект 11: [Анализ и прогнозирование временных рядов](./project_11_time_series_prophet/)**
    *   *Технологии:* Statsmodels (ADF-test), Pmdarima (`auto_arima`), Prophet.
    *   *Суть задачи:* Статистический анализ временного ряда производства электроэнергии. Проверка на стационарность, аддитивная декомпозиция ряда на тренд и сезонность. Построение и долгосрочное прогнозирование с использованием классической модели **SARIMA** и алгоритмов **Prophet** от Meta.
*   **Проект 12: [Комплексный ML-пайплайн определения типов личности](./project_12_personality_prediction/)**

    *   *Суть задачи:* Решение задачи классификации типов личности на основе поведенческих факторов. Проектирование синтетических фич (Feature Engineering), обработка пропущенных значений. Оптимизация 5 различных классов моделей через `Optuna` с достижением итоговой метрики **Accuracy = 0.9715**.

## 🚀 Инструкция по развертыванию всего репозитория

Для локального запуска проектов и воспроизведения результатов вам потребуется установленная среда Python 3.11+.

1.  **Клонируйте репозиторий:**
    ```bash
    git clone https://github.com
    cd ml-data-science-portfolio
    ```

2.  **Создайте и активируйте виртуальное окружение:**
    ```bash
    python -m venv venv
    # Для Linux/macOS:
    source venv/bin/activate
    # Для Windows:
    venv\Scripts\activate
    ```

3.  **Установите все зависимости репозитория:**
    В корневом каталоге находится общий файл со всеми необходимыми пакетами:
    ```bash
    pip install -r requirements.txt
    ```

4.  **Запуск:** Вы можете переходить в папку любого интересующего вас проекта и запускать исполняемые `.py` скрипты либо открывать Jupyter-ноутбуки (`.ipynb`) для пошагового просмотра аналитики.
