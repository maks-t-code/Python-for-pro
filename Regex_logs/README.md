# Очистка и структурирование геоданных из сетевых логов (Python + RegEx + Pandas)

Проект представляет собой автоматизированное решение для парсинга и валидации «грязных» данных из логов сетевого балансировщика (`durty_data.csv`). Цель скрипта — отфильтровать хаотичные логи, выделить из них корректные строковые адреса и географические координаты, очистить их от дубликатов и спецсимволов, а затем разложить по отдельным вкладкам в итоговом Excel-отчете.

---

## 📋 Описание алгоритма работы

Алгоритм обработки данных реализован пошагово и разделен на несколько логических этапов:

1.  **Чтение и первичная очистка строк**: Скрипт построчно считывает исходный файл `durty_data.csv` в кодировке UTF-8. На этом этапе из логов удаляются лишние кавычки, HTML-теги и битые строки с помощью регулярных выражений (`re.sub`).
2.  **Экстракция геокоординат**: С помощью регулярного выражения `^\d{2,3}[.]\d+,\s?\d{2,3}[.]\d+` в каждой строке ищется паттерн широты и долготы. Найденные совпадения заносятся в изолированный список координат.
3.  **Глубокая очистка адресов**: После извлечения координат из оставшейся текстовой части строки удаляются сами числа координат, битые кодировки символов (например, конструкции вида `\xD...`, `Ð`, `Ñ`), одиночные знаки препинания, скобки, а также лишние пробелы в начале и конце строк. Очищенный текст заносится в список адресов.
4.  **Дедупликация и фильтрация**:
    *   Данные преобразуются в объекты `pandas.DataFrame`.
    *   Из таблицы координат удаляются пустые значения (`None` / `NaN`).
    *   Из обеих таблиц полностью удаляются дубликаты строк (`drop_duplicates`).
5.  **Финальный экспорт**: С помощью компонента `pd.ExcelWriter` формируется файл `results.xlsx`, внутри которого создаются два структурированных листа: **«Адреса»** и **«Координаты»**.

## 🛠 Технологический стек и требования

Проект оформлен в виде файла Jupyter Notebook (`.ipynb`) и использует базовые библиотеки:
*   `pandas` (и движок `openpyxl` для записи многостраничных файлов Excel)
*   `re` (встроенный текстовый парсер регулярных выражений Python)

Установка необходимых библиотек:
```bash
pip install pandas openpyxl
```

## 🚀 Инструкция по запуску

1.  Поместите исходный лог-файл `durty_data.csv` в корневую директорию со скриптом решения.
2.  Запустите код внутри среды Jupyter Notebook или выполните его как стандартный скрипт Python:
    ```bash
    python solution.py
    ```
3.  После выполнения в корне проекта появится готовый файл `results.xlsx`, готовый для дальнейшего тестирования API сервисов валидации адресов. В коде предусмотрен перехват исключений на случай отсутствия исходного файла логов (`FileNotFoundError`).
