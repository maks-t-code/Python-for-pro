# Анализ и прогнозирование временного ряда производства электроэнергии (Python)

Проект посвящен комплексному статистическому анализу и построения прогностических моделей для ежемесячного временного ряда объемов производства электроэнергии. В рамках исследования выполнен разведочный анализ данных (EDA), проведена проверка ряда на стационарность, осуществлена декомпозиция на компоненты и сопоставлено качество прогноза двух подходов: классического интегрированного авторегрессионного скользящего среднего с сезонной компонентой (**SARIMA**) и современной библиотеки автоматического прогнозирования **Prophet**.

---

## 📋 Этапы реализации проекта

1. **Загрузка и предобработка данных**: Импорт временного ряда с приведением временных меток к формату `datetime` и установкой даты в качестве индекса датасета.
2. **Разведочный анализ данных (EDA)**: 
   * Проверка на наличие пропущенных значений (пропуски не обнаружены).
   * Визуальный анализ распределения и структуры данных.
   * Декомпозиция ряда на тренд, сезонность и остатки (Residuals) с использованием аддитивной модели. Выявлена четкая годовая цикличность с пиками в зимние периоды.
3. **Тестирование на стационарность**: Проведение расширенного теста Дики — Фуллера (ADF-test) для определения интегрируемости ряда.
4. **Валидация**: Разделение исходного датасета на обучающую (train) и тестовую (test) выборки в хронологическом порядке.
5. **Построение модели SARIMA**: Автоматический подбор оптимальных параметров порядка авторегрессии, дифференцирования и скользящего среднего $(p, d, q) \times (P, D, Q)_s$ с помощью алгоритма `auto_arima` (библиотека `pmdarima`) по критерию AIC.
6. **Построение модели Prophet**: Обучение аддитивной модели Prophet с учетом годовой сезонности и автоматическим поиском точек излома тренда (changepoints).
7. **Оценка качества прогнозов**: Сравнительный анализ точности моделей на отложенной тестовой выборке по метрикам `MSE`, `MAE` и `MAPE`.

---

## 🛠 Технологический стек

* **Язык разработки:** Python 3.11
* **Библиотеки для анализа и моделирования:**
  * `pandas`, `numpy` — обработка данных и математические вычисления
  * `statsmodels` — статистические тесты (ADF-test), декомпозиция и построение моделей `SARIMAX`
  * `pmdarima` — автоматизированный подбор гиперпараметров (`auto_arima`)
  * `prophet` — прогнозирование на основе аддитивных моделей
  * `scikit-learn` — расчет метрик качества моделей (`sklearn.metrics`)
  * `matplotlib` — визуализация данных, графиков автокорреляции (ACF/PACF) и прогнозов

## 📈 Результаты исследования и метрики качества

### 1. Тест Дики — Фуллера (ADF-test)
* **Статистика ADF:** -2.257
* **p-value:** 0.186 ( > 0.05)
* **Вывод:** Нулевая гипотеза не отвергается, исходный временной ряд является **нестационарным** и имеет выраженный восходящий тренд.

### 2. Оптимальные параметры SARIMA
По результатам stepwise-поиска алгоритмом `auto_arima` лучшей признана конфигурация:
$$\text{SARIMAX}(1, 0, 0) \times (0, 1, 1)_{12} \text{ с интерцептом}$$

### 3. Сравнение моделей на тестовой выборке

| Модель / Метрика | MSE | MAE | MAPE |
| :--- | :---: | :---: | :---: |
| **SARIMA** | **26.17** | **4.04** | **3.80%** |
| **Prophet** | 85.05 | 7.68 | 7.82% |

### Итоговый аналитический вывод:
Обе модели успешно уловили сложную структуру ряда и сильную годовую сезонность. Однако на отложенной тестовой выборке **классическая модель SARIMA показала значительно более высокую точность**, опередив Prophet по всем ключевым метрикам. Ошибка `MAPE` для SARIMA составила всего **3.8%**, что свидетельствует о высоком качестве прогноза и применимости модели для промышленного планирования энергопотребления.
