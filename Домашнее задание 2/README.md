# Домашнее задание №2

## Описание

Данный репозиторий содержит решения домашнего задания №2 по курсу, включающие три основных задания, направленных на анализ данных с использованием библиотек NumPy, Pandas, Matplotlib и Seaborn.

## Структура проекта

- **Задание 1**: Анализ данных о студентах с использованием NumPy
- **Задание 2**: Анализ данных о продажах с использованием Pandas
- **Задание 3**: Визуализация данных с использованием Seaborn

## Задание 1: Анализ данных о студентах (NumPy)

В данном задании анализируются данные об оценках студентов по трем предметам: математика, физика и информатика.

### Выполненные задачи:
- Расчет средней оценки по каждому предмету
- Вычисление медианной оценки по каждому предмету
- Расчет стандартного отклонения по каждому предмету
- Определение предмета с самой высокой средней оценкой

### Используемые технологии:
- NumPy

### Результаты:
- Самая высокая средняя оценка зафиксирована по информатике (87.4)
- Наименьший разброс оценок также наблюдается по информатике (стандартное отклонение 4.08)

## Задание 2: Анализ данных о продажах (Pandas)

В этом задании анализируются данные о ежемесячных продажах за последний год.

### Выполненные задачи:
- Расчет общего объема продаж за год
- Вычисление среднего объема продаж в месяц
- Определение месяца с наибольшим и наименьшим объемом продаж
- Построение линейного графика изменения объема продаж по месяцам

### Используемые технологии:
- Pandas
- Matplotlib

### Результаты:
- Общий объем продаж за год: 240,000
- Средний объем продаж в месяц: 20,000
- Наибольший объем продаж в декабре (26,000)
- Наименьший объем продаж в мае (14,000)

## Задание 3: Визуализация данных (Seaborn)

В задании используется датасет `tips` из библиотеки Seaborn для создания различных типов графиков.

### Построенные графики:
1. **Линейный график** - зависимость времени прихода посетителей от дня недели
2. **Столбчатый график** - распределение общего счета по курящим и некурящим посетителям
3. **Гистограмма** - распределение размера чаевых с разделением по курящим и некурящим
4. **Диаграмма рассеяния** - зависимость чаевых от общего счета

### Используемые технологии:
- Seaborn
- Matplotlib
- Pandas

```bash
pip install numpy pandas matplotlib seaborn
```
