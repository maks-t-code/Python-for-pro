# Автоматизация обработки медицинских анализов (Python + PostgreSQL + Pandas)

Проект представляет собой инструмент для обработки и расшифровки зашифрованных медицинских анализов пациентов клиники. Скрипт интегрирует данные из файлов Excel (`medicine.xlsx`) со справочниками из базы данных PostgreSQL для автоматического выявления отклонений в показателях здоровья.

Проект содержит два режима работы: базовый (`easy.py`) и продвинутый (`hard.py`).

---

## ✨ Функционал проекта

### 1. Базовый режим (Скрипт `easy.py`)
*   **Источник данных**: Лист `easy` исходного файла Excel.
*   **Логика**: Выявление пациентов, у которых нарушена норма (значение ниже минимального или выше максимального референса) **хотя бы по одному анализу**.
*   **Результат**: Формирование файла `result_easy.xlsx` с указанием ФИО, телефона, названия анализа и текстового заключения (`Повышен` / `Понижен`).

### 2. Продвинутый режим (Скрипт `hard.py`)
*   **Источник данных**: Лист `hard` исходного файла Excel.
*   **Логика**: Скрипт обрабатывает как количественные показатели, так и качественные (например, текстовые маркеры `Положит.`, `+`, `Отриц.`, `-`). Выявляются только те пациенты, у которых обнаружено отклонение **по двум и более анализам одновременно**.
*   **Результат**: Формирование файла `result_hard.xlsx` со столбцами ФИО, телефон, название анализа и расширенным заключением (`Повышен`, `Понижен` или `Положительный`).

---

## 🛠 Технологический стек и требования

Для работы проекта необходима установленная СУБД **PostgreSQL** и Python версии 3.x со следующими зависимостями:
*   `pandas` (и библиотека `openpyxl` для работы с форматом `.xlsx`)
*   `psycopg2-binary` (для подключения к PostgreSQL)

Вы можете установить библиотеки командой:
```bash
pip install pandas openpyxl psycopg2-binary
```

---

## 💾 Структура базы данных и подготовка

Перед запуском скриптов в вашей базе данных PostgreSQL необходимо создать таблицы справочников и наполнить их данными (соответствующий SQL-код содержится внутри Jupyter Notebook):
*   `med_name` — справочник пациентов (идентификатор, ФИО, контактный телефон).
*   `med_an_name` — справочник видов исследований (идентификатор, название, признак качественного анализа, минимальное и максимальное референсные значения).

---

## 🚀 Настройка и запуск

1. Разместите файл с зашифрованными анализами `medicine.xlsx` в одной директории со скриптами.
2. Откройте нужный скрипт (`easy.py` или `hard.py`) и настройте параметры подключения к вашей базе данных PostgreSQL в блоке конфигурации:
```python
DB_NAME = 'postgres'
DB_USER = 'postgres'
DB_PASSWORD = 'your_password'
DB_HOST = 'localhost'
DB_PORT = '5432'
```
3. Запустите скрипт через терминал:
```bash
python easy.py
# или
python hard.py
```

После успешного выполнения в консоли отобразится отчет, а в папке проекта появится итоговый файл (`result_easy.xlsx` или `result_hard.xlsx`), в котором ФИО пациентов будут автоматически отсортированы по алфавиту для удобства работы медицинского персонала.
