# Medical Test Results Analyzer

## 📋 Описание проекта

Проект представляет собой решение для обработки и анализа результатов медицинских анализов. Данные хранятся в зашифрованном Excel-файле и расшифровываются с использованием базы данных PostgreSQL. Программа выявляет отклонения в анализах пациентов и формирует структурированные отчеты.

## 🎯 Выполненные задачи

### Режим Easy (easy.py)
✅ Загрузка данных из листа `easy` Excel-файла  
✅ Расшифровка кодов анализов через таблицу `med_an_name`  
✅ Получение информации о пациентах из таблицы `med_name`  
✅ Выявление пациентов с любым отклонением (хотя бы один анализ не в норме)  
✅ Определение типа отклонения: "Повышен" или "Понижен"  
✅ Формирование Excel-отчета с колонками: ФИО, телефон, название анализа, заключение  
✅ Сортировка результатов по алфавиту

### Режим Hard (hard.py)
✅ Загрузка данных из листа `hard` Excel-файла  
✅ Обработка как числовых, так и качественных анализов  
✅ Расшифровка всех типов анализов через БД  
✅ Выявление отклонений: "Повышен", "Понижен", "Положительный"  
✅ Фильтрация пациентов с 2+ отклонениями  
✅ Формирование детального Excel-отчета  
✅ Сортировка результатов по алфавиту

## 🛠 Используемые технологии

- **Python 3.8+** — язык программирования
- **PostgreSQL 12+** — реляционная база данных
- **pandas** — обработка и анализ данных
- **psycopg2** — подключение к PostgreSQL
- **openpyxl** — работа с Excel-файлами

## ⚙️ Настройка и установка

### 1. Установка зависимостей

```bash
pip install pandas psycopg2 openpyxl
```

### 2. Настройка базы данных

Создайте таблицы в PostgreSQL:

```sql
-- Таблица с нормами анализов
CREATE TABLE med_an_name (
    id varchar(10) NULL,
    name varchar(200) NULL,
    is_simple bpchar(1) NULL,
    min_value numeric(18, 2) NULL,
    max_value numeric(18, 2) NULL
);

-- Таблица с информацией о пациентах
CREATE TABLE med_name (
    id int4 NULL,
    name varchar(50) NULL,
    phone varchar(20) NULL
);
```

Заполните таблицы данными из предоставленных INSERT-запросов.

### 3. Настройка подключения к БД

В каждом скрипте измените параметры подключения:

```python
DB_NAME = 'your_database'
DB_USER = 'your_username'
DB_PASSWORD = 'your_password'
DB_HOST = 'localhost'
DB_PORT = '5432'
```

## 🔍 Особенности реализации

### Обработка данных
- **Числовые анализы**: сравниваются с минимальным и максимальным нормальными значениями
- **Качественные анализы**: проверяются на наличие ключевых слов ('Положит.', '+', 'Отриц.', '-')
- **Обработка NULL значений**: заменяются на 0 для корректного сравнения

### Логика отбора
- **Easy режим**: пациенты с 1+ отклонениями
- **Hard режим**: пациенты с 2+ отклонениями

### Выходной формат
- Excel-файл с четкой структурой
- Автоматическая сортировка по ФИО
- Информативные названия колонок на русском языке

## ⚠️ Важные замечания

1. Файл `medicine.xlsx` должен находиться в той же папке, что и скрипт
2. База данных PostgreSQL должна быть запущена и доступна
3. Таблицы `med_an_name` и `med_name` должны быть заполнены данными
4. Для качественных анализов используйте стандартные значения из задания

## 🐛 Устранение неполадок

| Ошибка | Решение |
|--------|---------|
| Ошибка подключения к БД | Проверьте параметры подключения и запущен ли PostgreSQL |
| FileNotFoundError | Убедитесь, что medicine.xlsx находится в рабочей папке |
| Ошибка типов данных | Проверьте формат значений в Excel-файле |
| Ошибка при чтении SQL | Проверьте существование таблиц в базе данных |

## 👨‍💻 Обработка ошибок

Программа включает обработку следующих исключений:
- Ошибки подключения к базе данных
- Отсутствие файла medicine.xlsx
- Ошибки при работе с базой данных
- Общие непредвиденные ошибки

Каждая ошибка логируется с понятным сообщением для пользователя.
