# Payment Reason Normalizer

## 📋 Описание проекта

Проект предназначен для нормализации и приведения к единому формату текстовых описаний (полей `reason`) из таблицы платежей. С использованием регулярных выражений скрипты преобразуют различные варианты написания номеров договоров и дат к стандартному формату, указанному в поле `reason_correct`.

## 🎯 Постановка задачи

Дана таблица `payments` с полями:
- `reason` - пользовательская формулировка назначения платежа
- `reason_correct` - ожидаемый системой формат

Необходимо с помощью регулярных выражений привести как можно больше значений `reason` к формату `reason_correct`.

## 🔍 Алгоритм преобразования

### Easy режим:
1. Замена обратных слешей на прямые (`\` → `/`)
2. Удаление лишних символов в начале/конце строки
3. Нормализация пробелов вокруг дат
4. Удаление множественных пробелов

### Hard режим (расширенный):
1. **Замена спецсимволов:** `\` → `/`, удаление `_`, `.`
2. **Нормализация разделителей:** приведение всех разделителей к пробелам
3. **Преобразование дат:** приведение различных форматов дат к единому виду:
   - `дд.мм.гггг` → `дд.мм.гггг`
   - `дд/мм/гггг` → `дд.мм.гггг`
   - `дд мм гггг` → `дд.мм.гггг`
   - `дд.мм.гг` → `дд.мм.20гг`
4. **Удаление лишних символов:** букв, знаков `#`, `№`, `-` и т.д.
5. **Нормализация формата:** приведение к виду `номер/число от дата`

## 📊 Примеры преобразований

| Исходный текст (reason) | Результат (reason_correct) |
|-------------------------|---------------------------|
| `83666\22 от 31.10.2010` | `83666/22 от 31.10.2010` |
| `77182/55    08. 10.2013` | `77182/55 от 08.10.2013` |
| `1749\74 от 16.03.2012` | `1749/74 от 16.03.2012` |

## ⚠️ Особенности реализации

### Easy скрипт
- Обрабатывает только первые 10 записей
- Использует базовые регулярные выражения
- Подходит для демонстрации подхода

### Hard скрипт
- Обрабатывает все 1009 записей
- Использует сложные регулярные выражения
- Учитывает множество форматов дат
- Обрабатывает случаи с несколькими договорами (разделенные запятой)
- Достигает 99% точности

## 🐛 Известные ограничения

1. Некоторые записи могут содержать нестандартные форматы, требующие ручной обработки
2. Скрипт не обрабатывает регистр букв (все удаляется)
3. В редких случаях может некорректно обрабатывать даты с однозначными числами
