# Очистка и нормализация текстовых данных с помощью Регулярных Выражений (Python + SQLAlchemy + RegEx)

Проект представляет собой интеллектуальный инструмент для разбора, очистки и приведения неструктурированных комментариев пользователей к строгому системному формату (шаблону). Скрипт извлекает хаотично записанные платежные назначения из базы данных PostgreSQL, обрабатывает их с помощью сложных регулярных выражений и оценивает точность совпадения с эталоном.

Проект содержит два режима работы: базовый (`easy`) для первых 10 строк таблицы и продвинутый (`hard`) для обработки всего датасета.

---

## ✨ Функционал проекта

### 1. Базовый режим (Решение `easy`)
*   **Логика**: Выборка первых 10 строк из таблицы `payments`.
*   **Обработка**: Очистка от экранирующих символов, удаление начальных/конечных пробелов и базовое выравнивание предлогов `от`.
*   **Результат**: **100% совпадение** обработанных строк с ожидаемым эталоном (`reason_correct`). Экспорт результатов в `result_easy.xlsx`.

### 2. Продвинутый режим (Решение `hard`)
*   **Логика**: Полное сканирование и обработка всей таблицы (1009 записей).
*   **Текстовый парсинг**: Скрипт справляется со сверхсложным хаотичным вводом: удаляет лишний текст (слова «оплата», «договор», «кредит», «рублей»), чистит нерелевантные символы (`#`, `№`, `_`), исправляет опечатки и пробелы вокруг разделителей номеров договоров (`/`).
*   **Интеллектуальное распознавание дат**: Скрипт приводит даты к единому стандарту `ДД.ММ.ГГГГ` (добавляет ведущие нули к дням и месяцам, раскрывает сокращенные года `13` -> `2013` и исправляет разделители).
*   **Результат**: Достигнут показатель точности **99.01% совпадений** на всем объеме данных. Экспорт результатов в `result_hard.xlsx`.

## 🛠 Технологический стек и требования

Проект разработан на Python 3.x и использует следующие библиотеки:
*   `pandas` (и библиотека `openpyxl` для генерации отчетов `.xlsx`)
*   `SQLAlchemy` (ORM для безопасного и удобного подключения к СУБД)
*   `psycopg2-binary` (драйвер для работы с PostgreSQL)
*   `re` (встроенный модуль Python для работы с регулярными выражениями)

Установка зависимостей:
```bash
pip install pandas openpyxl sqlalchemy psycopg2-binary
```

---

## 💾 Схема таблицы в БД

Скрипт взаимодействует с таблицей `payments`, которая имеет следующую структуру:
*   `dt` (date) — дата совершения платежа.
*   `amt` (numeric) — сумма платежа.
*   `reason` (varchar) — исходный текст комментария, написанный пользователем вручную.
*   `reason_correct` (varchar) — эталонная строка, к которой необходимо привести исходный комментарий.

## 🚀 Настройка и запуск

1. Откройте код нужного решения (блок `easy` или `hard`) и укажите строку подключения к вашей базе данных в конструкторе `create_engine`:
```python
# формат: 'postgresql://логин:пароль@хост:порт/имя_бд'
engine = create_engine('postgresql://postgres:your_password@localhost:5432/postgres')
```
2. Запустите скрипт:
```bash
python easy_solution.py  # Для проверки базового алгоритма
# или
python hard_solution.py  # Для запуска полного цикла нормализации
```

В консоль выведется итоговый процент совпадений, а сгенерированный Excel-файл будет содержать детальную таблицу сравнения: `reasons_result` (результат работы регулярных выражений) против `reasons_correct` (оригинальный системный эталон) с флагом проверки `compare`.
