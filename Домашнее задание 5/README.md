# Address and Geo-Coordinates Extractor

## 📋 Описание проекта

Проект предназначен для очистки и извлечения структурированных данных из "грязного" CSV-файла, содержащего смешанные записи адресов и географических координат. Из необработанных логов сетевого балансера выделяются только строки, похожие на адреса или гео-координаты, с последующим разделением на отдельные листы Excel-файла.

## 🎯 Постановка задачи

Из файла `durty_data.csv` необходимо:
1. Выделить строки, похожие на адреса и гео-координаты
2. Удалить дубликаты и кавычки
3. Разложить результаты на 2 разных листа Excel файла:
   - Строковые адреса
   - Гео-координаты

## 🛠 Используемые технологии

- **Python 3.8+**
- **Библиотеки:**
  - `pandas` - обработка и структурирование данных
  - `re` - регулярные выражения для очистки и извлечения данных

## 📊 Алгоритм работы

### 1. Загрузка данных
- Открытие файла `durty_data.csv` с кодировкой UTF-8

### 2. Очистка данных
Для каждой строки выполняются следующие операции:

#### Общая очистка:
- Удаление кавычек (`"`)
- Удаление XML-подобных тегов (`<...>`)

#### Извлечение координат:
- Поиск строк, соответствующих формату координат:
  - `XX.XXXX, XX.XXXX` или `XX.XXXX,XX.XXXX`
  - где `X` - цифры (2-3 цифры до точки)
- Сохранение найденных координат в отдельный список

#### Очистка адресов:
- Удаление координат из строк
- Удаление закодированных символов:
  - Строки с `\\xD` 
  - Строки с `Ð` (кириллица в неправильной кодировке)
  - Строки с `Ñ` (кириллица в неправильной кодировке)
- Удаление лишних пробелов в начале и конце строк
- Удаление пустых строк и одиночных символов

### 3. Обработка данных

#### Адреса:
- Создание DataFrame
- Удаление дубликатов
- Удаление первой пустой строки (артефакт обработки)

#### Координаты:
- Создание DataFrame
- Удаление строк с пустыми значениями (None)
- Удаление дубликатов

### 4. Сохранение результатов
- Создание Excel-файла с двумя листами:
  - **Адреса** - все уникальные адреса
  - **Координаты** - все уникальные гео-координаты

## 🔍 Примеры извлечения

### Координаты:
```
Исходная строка: "55.751244, 37.618423"
Результат: 55.751244, 37.618423
```

### Адреса:
```

```

## 📈 Выходные данные

### Лист "Адреса"
Содержит уникальные адреса, извлеченные из исходного файла после очистки.

### Лист "Координаты"
Содержит уникальные пары координат в формате:
- `широта, долгота` (с пробелом после запятой)
- `широта,долгота` (без пробела)

## ⚠️ Важные замечания

1. **Файл должен находиться в той же папке**, что и скрипт/ноутбук
2. **Кодировка файла** должна быть UTF-8
3. **Обработка ошибок**:
   - `FileNotFoundError` - если файл не найден
   - `Exception` - другие непредвиденные ошибки

## 🐛 Устранение неполадок

| Ошибка | Решение |
|--------|---------|
| `FileNotFoundError` | Проверьте наличие файла `durty_data.csv` в рабочей папке |
| Ошибка кодировки | Убедитесь, что файл сохранен в UTF-8 |
| Пустой результат | Проверьте формат данных в исходном файле |
