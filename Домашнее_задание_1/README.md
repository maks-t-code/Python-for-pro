# Шифр Цезаря

Простая реализация шифра Цезаря для русского алфавита с функциями кодирования и декодирования методом полного перебора (brute force).

## Описание

Данный проект содержит две основные функции:
- **Шифрование** строки с заданным сдвигом
- **Дешифрование** методом перебора всех возможных сдвигов

## Установка

1. Клонируйте репозиторий:
```bash
git clone https://github.com/yourusername/caesar-cipher.git
cd caesar-cipher
```

2. Создайте виртуальное окружение (рекомендуется):
```bash
python -m venv .venv
source .venv/bin/activate  # Для Linux/Mac
# или
.venv\Scripts\activate     # Для Windows
```

## Использование

### Шифрование

```python
from caesar_cipher import encryption

message = "ПРИВЕТ МИР"
shift = 5
encrypted = encryption(message, shift)
print(encrypted)  # Вывод: ФХНЗКЧ СНХ
```

### Дешифрование

```python
from caesar_cipher import decryption

encrypted_message = "ФХНЗКЧ СНХ"
results = decryption(encrypted_message)
for shift, text in results:
    print(f"Сдвиг {shift}: {text}")
```

## Особенности реализации

- Используется русский алфавит (33 буквы)
- Регистр букв не важен - все строки приводятся к верхнему регистру
- Пробелы и другие небуквенные символы сохраняются без изменений
- Дешифрование выполняется методом полного перебора всех 33 возможных сдвигов

## Алгоритм работы

### Шифрование
1. Для каждого символа в строке проверяется, является ли он буквой русского алфавита
2. Если да, то находится его индекс в алфавите и к нему прибавляется сдвиг
3. Вычисляется новый индекс по модулю длины алфавита
4. Символ заменяется на соответствующий в новом индексе

### Дешифрование (Brute Force)
1. Перебираются все возможные сдвиги от 1 до 32 (33-1)
2. Для каждого сдвига выполняется обратное преобразование
3. Результаты сохраняются в виде списка кортежей (сдвиг, результат)
