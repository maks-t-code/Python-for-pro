# Прогнозирование оттока клиентов банка (Customer Churn)

## 📖 Описание проекта

Данный проект представляет собой комплексное исследование по машинному обучению, целью которого является прогнозирование оттока клиентов (churn) банка. На основе исторических данных о клиентах мы строим и сравниваем несколько моделей, чтобы определить, покинет ли клиент банк или останется.

**Ключевые аспекты:**
*   ✅ Решение задачи бинарной классификации.
*   ⚙️ Сравнение моделей: Logistic Regression, Decision Tree, XGBoost, CatBoost.
*   🚀 Автоматический подбор гиперпараметров с помощью **Optuna**.
*   🔍 Интерпретация результатов с использованием **SHAP** и **Permutation Feature Importance**.
*   📊 Визуализация влияния признаков на предсказания модели.

## 🗂️ Данные

**Датасет:** 165 034 записи о клиентах банка с 14 признаками.

**Основные признаки:**
*   Демографические: `Age`, `Gender`, `Geography` (страна).
*   Финансовые: `CreditScore`, `Balance`, `EstimatedSalary`, `NumOfProducts`.
*   Поведенческие: `Tenure` (срок обслуживания), `IsActiveMember`, `HasCrCard`.
*   **Целевая переменная:** `Exited` (0 — клиент остался, 1 — клиент ушел).

## 🤖 Модели и подход

Все модели обучались с использованием `Pipeline`, что позволило стандартизировать процесс предобработки данных и обучения.

### Этапы работы:

1.  **Предобработка (Preprocessing):**
    *   Удаление неинформативных признаков (`id`, `CustomerId`, `Surname`).
    *   Масштабирование числовых признаков (`StandardScaler`).
    *   One-Hot Encoding категориальных признаков (`Geography`, `Gender`).

2.  **Обучение моделей:**
    *   **Logistic Regression**
    *   **Decision Tree**
    *   **XGBoost**
    *   **CatBoost**

3.  **Оптимизация:**
    *   Для каждой модели был проведен подбор гиперпараметров с использованием библиотеки **Optuna** (100 испытаний с 5-фолдовой кросс-валидацией).

## 📊 Результаты

Лучшей моделью по метрике ROC-AUC и F1-score оказался **CatBoost**.

| Модель | Accuracy | Precision | Recall | F1-score | ROC-AUC |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **CatBoost (Лучшая)** | **0.86** | **0.75** | **0.51** | **0.61** | **0.883** |
| Logistic Regression | 0.83 | 0.69 | 0.38 | 0.49 | 0.815 |

## 🔍 Интерпретация модели

Для обеспечения прозрачности модели были использованы два метода интерпретации:

### 1. Permutation Feature Importance

Метод показывает, как падает качество модели (ROC-AUC) при случайном перемешивании значений каждого признака. Чем выше падение, тем важнее признак.

![Permutation Importance](images/permutation_importance.png)

**Вывод:** `NumOfProducts` является наиболее важным признаком. Чем больше продуктов у клиента, тем он лояльнее.

### 2. SHAP (SHapley Additive exPlanations)

#### Глобальная интерпретация
*   **SHAP Summary Bar Plot** подтверждает, что наибольший вклад в предсказания вносят `NumOfProducts`, `Age` и `Balance`.
*   **SHAP Beeswarm Plot** показывает характер влияния признаков:
    *   `NumOfProducts`: Высокие значения снижают вероятность оттока.
    *   `Age` и `Balance`: Высокие значения увеличивают вероятность оттока.

![SHAP Summary Bar](images/shap_summary_bar.png)

#### Локальная интерпретация
**SHAP Waterfall Plots** позволяют объяснить, почему модель приняла конкретное решение для каждого клиента, разлагая предсказание на вклад каждого признака.

![SHAP Waterfall](images/shap_waterfall.png)
