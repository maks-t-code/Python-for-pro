# Прогноз оттока клиентов банка (Customer Churn Prediction)

[![Python](https://img.shields.io/badge/Python-3.8+-blue.svg)](https://www.python.org/)
[![Jupyter](https://img.shields.io/badge/Jupyter-Notebook-orange.svg)](https://jupyter.org/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

Этот проект представляет собой комплексное исследование по машинному обучению, направленное на прогнозирование оттока клиентов (Churn) для условного банка. Основная цель — по историческим данным клиентов определить, с высокой вероятностью уйдет клиент или останется.

**Ключевые аспекты проекта:**
*   Сравнение нескольких алгоритмов классификации.
*   Использование пайплайнов (`Pipeline`) для стандартизации процесса предобработки и обучения.
*   Автоматический подбор гиперпараметров с помощью Optuna.
*   Глубокая интерпретация результатов с использованием методов **SHAP** и **Permutation Feature Importance**.

## 🎯 Задача и Данные

### Задача
Разработать модель машинного обучения для бинарной классификации, которая по профилю клиента предсказывает, покинет ли он банк (`Exited = 1`) или останется (`Exited = 0`).

### Данные
Датасет содержит информацию о 165,034 клиентах и 14 признаках, включая:

*   **Демографические:** `Age`, `Gender`, `Geography` (страна).
*   **Финансовые:** `CreditScore`, `Balance`, `EstimatedSalary`, `NumOfProducts`.
*   **Поведенческие:** `Tenure` (срок обслуживания), `IsActiveMember`, `HasCrCard`.
*   **Идентификаторы:** `id`, `CustomerId`, `Surname` (были исключены из модели).

> **Целевая переменная:** `Exited` (0 — клиент остался, 1 — клиент ушел).

## 🤖 Используемые Модели

В рамках работы были обучены и сравнены следующие модели:

1.  **Логистическая Регрессия (Logistic Regression)**
    *   *Базовый алгоритм, использованный для оценки линейных зависимостей.*
2.  **Дерево Решений (Decision Tree)**
    *   *Интерпретируемая модель, которая хорошо показывает нелинейные закономерности.*
3.  **XGBoost (eXtreme Gradient Boosting)**
    *   *Мощный алгоритм градиентного бустинга, часто показывающий лучшие результаты на табличных данных.*
4.  **CatBoost**
    *   *Еще один алгоритм градиентного бустинга, известный своей устойчивостью к категориальным признакам и высокой скоростью обучения.*

Все модели обучались внутри `Pipeline`, который включал:
*   **Предобработку:** Масштабирование (`StandardScaler`) для числовых признаков и One-Hot Encoding для категориальных (`Geography`, `Gender`).
*   **Оптимизацию:** Подбор гиперпараметров для каждой модели с помощью библиотеки **Optuna** (100 испытаний с кросс-валидацией на 5 фолдах).

## 📊 Ключевые Результаты

Лучшей моделью по совокупности метрик оказался **CatBoost**.

| Модель | Accuracy | Precision | Recall | F1-score | ROC-AUC |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **CatBoost (Лучшая)** | **0.86** | **0.75** | **0.51** | **0.61** | **0.883** |
| Logistic Regression | 0.83 | 0.69 | 0.38 | 0.49 | 0.815 |
| Decision Tree | 0.86 | 0.74 | 0.54 | 0.63 | 0.884 |
| XGBoost | 0.86 | 0.80 | 0.45 | 0.57 | 0.880 |

> **Интерпретация:** Несмотря на схожий Accuracy, CatBoost и Дерево Решений показывают лучший баланс между Precision и Recall (F1-score) и демонстрируют наивысшую разделяющую способность (ROC-AUC).

## 🔍 Интерпретация Модели

Для обеспечения "прозрачности" модели, на данных тестовой выборки были применены два метода интерпретации.

### 1. Permutation Feature Importance
Метод оценивает, как падает качество модели (ROC-AUC) при случайном перемешивании значений каждого признака. Чем сильнее падает качество, тем важнее признак.

![Permutation Importance](images/permutation_importance.png)

**Вывод:** Самым важным признаком является **`NumOfProducts`** (количество продуктов банка у клиента). Это логично, так как клиенты с большим числом продуктов, как правило, более лояльны.

### 2. SHAP (SHapley Additive exPlanations)
SHAP позволяет оценить **вклад каждого признака** в каждое конкретное предсказание модели.

*   **Глобальная важность (SHAP Summary Bar Plot)** подтверждает, что `NumOfProducts`, `Age` и `Balance` вносят наибольший вклад в прогнозы модели.
*   **Влияние на результат (SHAP Beeswarm Plot)** показывает, что:
    *   **Высокий возраст** (`Age`) и **наличие баланса** (`Balance`) увеличивают вероятность оттока (красные точки справа).
    *   **Большое количество продуктов** (`NumOfProducts`) снижает вероятность оттока (синие точки справа).

![SHAP Summary Bar](images/shap_summary_bar.png)

*   **Индивидуальные предсказания (Waterfall Plots)** позволяют "разложить" прогноз для каждого клиента, показывая, как признаки сдвинули предсказание от базового значения (ожидаемой вероятности по всей выборке) к финальному результату.

![SHAP Waterfall](images/shap_waterfall.png)
