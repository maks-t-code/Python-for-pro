## 🚀 Описание проекта

Цель проекта — провести полный цикл работы с временным рядом: от загрузки и разведочного анализа данных до построения, оценки и сравнения двух популярных моделей прогнозирования. В качестве датасета используются ежемесячные данные о производстве электроэнергии в США.

## 📊 Данные

*   **Название:** `Electric_Production.csv`
*   **Описание:** Набор данных содержит ежемесячные показатели производства электроэнергии в период с 1985 по 2018 год.
*   **Загрузка:** Данные загружаются из Google Drive с использованием `gdown`.

## 🛠️ Этапы работы

1.  **Загрузка данных:** Импорт данных и преобразование столбца с датой в формат `datetime` для использования в качестве индекса.
2.  **Разведочный анализ данных (EDA):**
    *   Визуализация временного ряда.
    *   Анализ на наличие пропусков и выбросов.
    *   Декомпозиция ряда на трендовую, сезонную и остаточную компоненты.
3.  **Анализ стационарности:** Проведение теста Дики-Фуллера (ADF) для проверки стационарности ряда. Вывод: ряд **не стационарен**.
4.  **Разделение на выборки:** Данные разделены на обучающую (первые 265 наблюдений) и тестовую (последние 132 наблюдения) выборки.
5.  **Автокорреляционный анализ:** Построение графиков ACF и PACF для определения порядка моделей.
6.  **Моделирование:**
    *   **SARIMA:** Автоматический подбор параметров с помощью `auto_arima`, обучение модели, прогнозирование и оценка качества на тестовой выборке.
    *   **Prophet:** Подготовка данных, обучение модели, прогнозирование и оценка качества.
7.  **Сравнение моделей:** Сравнение метрик качества (MSE, MAE, MAPE) и визуализация прогнозов.

## 📈 Модели и результаты

### Модель SARIMA

Модель `SARIMAX` с подобранными параметрами для учета сезонности (m=12).

*   **Лучшие параметры:**
    *   `order=(1, 0, 0)`
    *   `seasonal_order=(0, 1, 1, 12)`
*   **Метрики на тестовой выборке:**
    *   **MSE:** 26.17
    *   **MAE:** 4.04
    *   **MAPE:** 3.80%

![Сравнение SARIMA](https://imgur.com/your-sarima-plot.png) *(Замените на фактический путь к изображению)*

### Модель Prophet

Модель от Facebook для прогнозирования временных рядов с учетом тренда и сезонности.

*   **Метрики на тестовой выборке:**
    *   **MSE:** 85.05
    *   **MAE:** 7.68
    *   **MAPE:** 7.82%

![Сравнение Prophet](https://imgur.com/your-prophet-plot.png) *(Замените на фактический путь к изображению)*

## 📚 Используемые библиотеки

## 📝 Выводы

На основе проведенного исследования и сравнительного анализа метрик можно сделать следующие выводы:

*   **Модель SARIMA** показала значительно лучшие результаты по всем метрикам (MSE, MAE, MAPE) по сравнению с Prophet. Это указывает на то, что она лучше улавливает структуру данного временного ряда.
*   **Модель Prophet**, несмотря на свою простоту и удобство использования, показала более высокую ошибку. Это может быть связано с тем, что для данного ряда структура тренда и сезонности хорошо описывается классической моделью SARIMA.

**Итог:** Для прогнозирования данного временного ряда предпочтительной является модель **SARIMA**.
