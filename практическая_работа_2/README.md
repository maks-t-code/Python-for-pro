# Практическая работа 2: Машинное обучение

## Описание проекта

Данная работа основана на данных конкурса [Playground Series - S4E10](https://www.kaggle.com/competitions/playground-series-s4e10/) с платформы Kaggle.

**Задача:** Спрогнозировать, останется ли клиент с аккаунтом или закроет его (например, уйдёт).

## Целевая переменная

- **Exited** — бинарный признак:
  - `0` — клиент остался
  - `1` — клиент ушёл

Доля клиентов с уходом (`1`) составляет **21.16%**.

## Используемые технологии

- `pandas`, `numpy` — работа с данными
- `scikit-learn` — машинное обучение
- `matplotlib`, `seaborn` — визуализация

## Этапы выполнения

### 1. Загрузка и первичный анализ данных
- Датасет загружен с Google Drive
- Выполнен разведочный анализ (EDA)
- Построена тепловая карта корреляций

### 2. Предобработка данных
- Удалены неинформативные признаки:
  - `id`, `CustomerId`, `Surname`
- Категориальные признаки (`Geography`, `Gender`) закодированы с помощью **One-Hot Encoding**
- Числовые признаки масштабированы с помощью **StandardScaler**
- Пропуски в данных отсутствуют
- Выбросы не требуют обработки (все значения укладываются в нормальный диапазон)

### 3. Разделение данных
- Данные разделены на обучающую и тестовую выборки в соотношении **75% / 25%**
- Использована **стратификация** по целевому признаку для сохранения баланса классов

### 4. Построение моделей

#### Модель 1: Логистическая регрессия (без регуляризации)
```python
LogisticRegression(max_iter=1000, random_state=42)
```

#### Модель 2: Логистическая регрессия с L2-регуляризацией
```python
LogisticRegression(penalty='l2', C=1, solver='liblinear', random_state=42)
```

### 5. Оценка качества моделей

| Метрика | Логистическая регрессия | Логистическая регрессия с регуляризацией |
|---------|------------------------|-------------------------------------------|
| **Accuracy** | 0.83 | 0.83 |
| **Precision** | 0.69 | 0.69 |
| **Recall** | 0.38 | 0.38 |
| **F1-score** | 0.49 | 0.49 |
| **ROC-AUC** | 0.815 | 0.815 |

### 6. Выводы

Обе модели показали идентичные результаты по всем метрикам качества.

**Рекомендация:** Использовать модель **логистической регрессии с регуляризацией**.

**Обоснование:**
- Регуляризация помогает снизить риск переобучения
- Модель становится более устойчивой к шумам в данных
- При одинаковых метриках качества предпочтение отдаётся более простой и устойчивой модели
